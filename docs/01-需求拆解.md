# 01 需求拆解

> 输入：《知识探索卡片系统策划方案》（九个章节）。
> 拆解原则：**可实现性优先**——每个功能都回答"一期怎么做、做到什么程度、做不到怎么降级"，不做无法验收的宏大需求。

---

## 1. 拆解方法与优先级定义

- 按方案九章归纳为 **7 个能力域**（D1–D7），每个功能项编号 `FR-域-序号`。
- 优先级与方案的三期建设对齐：
  - **P0（一期 MVP）**：对应方案"第一阶段：验证核心体验"，必须支撑第九章的核心验收标准。
  - **P1（二期）**：对应"第二阶段：扩展服务与协作"。
  - **P2（三期）**：对应"第三阶段：专题经营与商业化"。
- 每条 P0 功能给出**验收要点**；跨功能的验收场景见 §4。

### 一期核心验收（来自方案第九章，逐条转化为可测标准）

| # | 方案原文 | 转化为可测验收 |
|---|---------|--------------|
| A1 | 用户能够连续完成至少三次有新信息的探索 | 一次会话内，通过入口或服务产生 ≥3 个不同知识对象的节点，且后一节点包含前一节点未出现过的实体/事实/出处 |
| A2 | 回到历史节点建立分支 | 在"我的路径"中点击任一历史节点，继续探索产生的新节点挂在该节点之下，标记为分支，不影响原分支 |
| A3 | 用一句话新增入口并获得预览 | 输入一句话 ≤30s 内返回可编辑的入口配置 + 一次试运行结果；个人入口直接保存成功 |
| A4 | 分享选定路径和结果 | 分享链接免登录可浏览，内容与创建时选定的一致（快照） |
| A5 | 接收者从指定节点继续且不覆盖原路径 | 接收者点击"沿此路径继续"后生成自己的会话副本，原分享者路径无任何变更 |

## 2. 角色与权限（RBAC）

| 角色 | 说明 | 关键权限 |
|------|------|---------|
| 探索者（默认） | 所有注册用户 | 浏览已发布卡片、发起会话/服务、个人空间保存、新增**私人**入口、分享自己的路径与成果 |
| 创作者 | 申请开通 | 在工作台创建/编辑卡片与入口，提交审核；管理自己名下内容 |
| 编辑（内容审核员） | 运营指定 | 审核公共卡片与入口、核验出处、种子内容生产 |
| 运营 | 平台管理 | 专题管理、数据看板、反馈处理、用户与配额管理 |

> 实现要点：角色是**平台级**的简单 RBAC，不引入机构级授权（P2）。"有权阅读 ≠ 有权转发"通过分享快照生成时的资源级权限过滤实现（见 02 文档 §9）。

## 4. 一期核心用户旅程（验收场景串联）

把 5 条验收串成一条端到端旅程，作为 MVP 的集成测试脚本：

1. 用户打开"岳麓书院"图文卡 → 点入口"为什么建在这里" → 得到讲解卡（含出处）【A1 第 1 次有效深入】
2. 在讲解卡追问"和城南书院什么关系" → 得到对比卡【A1 第 2 次】
3. 点"哪些人物与这里有关" → 时间线卡【A1 第 3 次，验收 A1 通过】
4. 打开"我的路径"→ 点回第 1 步节点 → 换方向探索"建筑空间" → 路径树出现分支【A2】
5. 对卡片说"给第一次来的家庭设计 60 分钟文化探索路线" → 得到入口配置草稿+试运行预览 → 保存到个人空间【A3】
6. 点"整理发现" → 勾选两支分支的节点 → 生成探索报告 → 分享为公开链接【A4】
7. 另一账号（未登录浏览器）打开链接 → 浏览路径与成果 → 登录后点"沿此路径继续" → 生成副本会话，原路径不变【A5】

## 5. 非功能需求与埋点

| 类别 | 要求 |
|------|------|
| 性能 | 卡片首屏 ≤1.5s；讲解服务完成 ≤20s（轮询间隔 2s）；分享页首开 ≤2s |
| 成本 | 单次讲解服务云 API 成本目标 ≤¥0.03（模型分级路由，见 02 文档 §6.5）；单用户日服务 30 次上限 |
| 内容安全 | 生成内容过敏感词过滤；面向公众服务需符合生成式 AI 管理相关规定（内容标识、留存） |
| 可维护性 | 模块化单体 + 核心路径自动化测试；卡片/入口/服务配置均为数据而非代码 |
| 审计 | 审核动作、状态流转、权限变更全留痕 |

**埋点事件（P0，服务 6 指标）**：`session_start / node_visit(含是否产生新知识对象) / service_run(含成败/时延/成本) / artifact_save / share_create / share_view / share_continue / entry_create(含试运行成败) / favorite`

## 6. MVP 裁剪决策汇总（可实现性核心）

方案能力 → 一期落地形态的映射，**每一条裁剪都有降级方案**：

| 方案能力 | 一期形态 | 降级/近似方式 |
|---------|---------|--------------|
| 8 种卡片形式 | 4 种模板（图文/对比/时间线/任务成果） | 音视频=图文卡嵌外链+时间戳；地图=路线清单卡；关系=图文卡内关联列表；互动卡不做 |
| 6 类智能体服务 | 2 类（讲解问答、成果整理） | 比较=讲解的对比模板；路线=任务卡模板+人工编排内容；推演演示不做 |
| 自然语言入口编排 | 三类白名单意图（链接已有卡/讲解服务/对比生成） | 抽取失败→引导改写或转手动表单；绝不开放工具/权限类意图 |
| 指定成员分享 | 仅自己/公开两档 | 群组分享二期 |
| 语音追问 | 文字 | 二期接 ASR |
| 图片识别搜索 | 无 | 二期 |
| 半自动审核 | 纯人工审核队列 | 专题少（3 个）+ 编辑 1 人可承受；二期加机器预检 |
| 断点续探/多端同步 | 会话保存与恢复 | 单设备为主，账户体系天然支持多端 |

**内容侧最小启动量**（不启动≠不发布，关键是专题能走通完整旅程）：
- 每专题精编 30–50 张种子卡片（含入口与出处）、每专题 1 个任务卡、知识单元 100–200 条；合计约 150 张卡 + 500 条知识单元即可支撑内测验收。

## 7. 风险清单与应对

| # | 风险 | 概率/影响 | 应对 |
|---|------|----------|------|
| R1 | 自然语言入口成功率低（方案已单列指标） | 高/高 | 收窄到 3 类白名单意图；试运行即真实验收（不合格不保存）；失败降级到表单；指标 <60% 则回收入口入口位，只保留模板入口 |
| R2 | LLM 幻觉/引用不实 | 中/高 | 只允许引用检索返回集合内的 citation id，校验失败自动剥离并标"归纳"；发布到公共区人工抽检；来源完整率纳入指标 |
| R3 | 种子内容生产成本被低估 | 高/中 | 内容生产工具先行（批量导入+模板表单）；先做 1 个专题跑通再复制；编辑产出纳入排期而非"顺带" |
