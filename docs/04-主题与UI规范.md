# 04 主题与 UI 规范

> 输入：`01-需求拆解`（信息结构）、`02-技术架构`（Vue3 双端 + Vant / Element Plus + shared 包）、`03-原型设计说明`（信息层级与既有视觉雏形）。
> 定位：**正式 UI 的单一事实来源**——双端（探索端 H5 / 工作台 Web / 分享页）共用一套 Token 与语义组件规范；所有对比度数值经 WCAG 2.1 实测（方法见 §2.7）。
> 配套可视化规范页：`prototype/styleguide.html`（单文件 HTML，浏览器直接打开），与本文档同源维护。
>
> **v1.1 设计方向：「纸墨编辑部」**——面向文化知识产品的编辑语言，而非后台模板：靛青（传统染料色）× 暖纸墨中性色 × 宋体显示层 × 细线与印章元素。v1.0 → v1.1 的全部取值变更见 §12 修正清单（B 部分）。

---

## 1. 设计原则

| # | 原则 | 落到规范 |
|---|------|---------|
| P1 | **可信可见** | 三档可信色（事实/归纳/生成）是**独占语义色**，任何组件不得挪用；可信徽标与出处角标是内容的一部分，随正文同层级渲染，不做弱化 |
| P2 | **内容前进、界面后退** | 大面积纸墨底，品牌色只承担「行动」与「当前态」；正文区无渐变、无大色块 |
| P3 | **来路常在** | 二级页顶部永远有返回 + 路径入口；路径/分支用主色点线呈现，用户任何时候知道自己在哪、从哪来 |
| P4 | **一屏一事** | 移动端每屏一个主任务；常驻操作（服务栏/追问条）固定底部并让出安全区 |
| P5 | **边界诚实** | 未上线功能一律灰态 + 分期标签（二期/三期），不伪装可用；服务失败、证据缺口、限额明说，不静默降级 |
| P6 | **纸墨编辑部** | 知识与品牌层（卡片标题 / 专题名 / 大标题 / 指标数）用宋体 900，工具层用黑体；卡片靠 1px 细线成型而非阴影；品牌强调面用实底 + 描边，不用渐变；系统图标一律 SVG，禁止 emoji 做控件图标 |

## 2. 色彩

### 2.1 色彩语义总表（锁色规则）

| 语义 | Token | 色值 | 独占性 |
|------|-------|------|--------|
| 行动/当前/链接 | `--ke-primary` | `#3A5FCD` | 主色仅用于可点、可继续、当前所在 |
| 事实（有出处陈述） | `--ke-fact` | `#1F7A4D` | **独占**：可信徽标、已核验、成功态共用（语义同源：已验证） |
| 归纳（推断综合） | `--ke-synth` | `#0E7490` | **独占**：仅可信徽标与归纳标记 |
| 生成（创意/受控生成） | `--ke-gen` | `#A85510` | **独占**：仅可信徽标与生成标记 |
| 警示（证据缺口/授权到期/驳回） | `--ke-warn` | `#8F5E12` | 仅警示场景 |
| 危险（停用/删除/失败） | `--ke-danger` | `#C0392B` | 仅破坏性与失败场景 |
| 私人（个人入口/个人空间） | `--ke-private` | `#6B46C1` | 仅"仅自己可见"语义 |
| 分期边界（二期/三期） | 中性灰 | — | **不用彩色**（P5：分期不是状态，是边界） |

> 三档可信色与警示/危险色不得用于装饰、营销、图表强调等任何其他场景；图表主色用品牌色阶。

### 2.2 品牌色 · 靛蓝（`#3A5FCD`）

| Token | 值 | 用途 |
|-------|-----|------|
| `--ke-primary` | `#3A5FCD` | 主按钮、链接/引用角标、当前项、入口图标底 |
| `--ke-primary-deep` | `#2F53B8` | hover/按下态、品牌实底面（继续探索卡等） |
| `--ke-primary-soft` | `#EEF2FD` | 次级按钮底、选中底、表头、徽标浅底 |

品牌强调面（继续探索卡、分享头图）= **深靛实底 + 1px 描边按钮**，不用渐变（v1.1 起移除 `--ke-primary-grad`）；图表柱体的品牌渐变是图表组件内部样式，非品牌 Token。

Element Plus 衍生色阶（工作台用，计算值见 §11.3）：light-3 `#758FDC` / light-5 `#9CAFE6` / light-7 `#C4CFF0` / light-8 `#D8DFF5` / light-9 `#EBEFFA` / dark-2 `#2E4CA4`。

### 2.3 三档可信色（系统核心资产）

对应 FR-S05（事实/归纳/生成三档标识）与 FR-E12（证据缺口）。**这是本产品最重要的视觉语言**，规则如下：

| 档位 | Token（文本/底） | 图形色 | 符号 | 徽标文案 |
|------|-----------------|--------|------|---------|
| 事实 | `#1F7A4D` / `#EAF5EF` | `--ke-fact-graphic #2E8B57` | ● 实心圆 = 落在出处上 | `● 事实` |
| 归纳 | `#0E7490` / `#E3F4F8` | 同文本色 | ◐ 半圆 = 由出处综合 | `◐ 归纳` |
| 生成 | `#A85510` / `#FDF1E7` | `--ke-gen-graphic #D97A2B` | ○ 空心圆 = 开放的生成 | `○ 生成` |

使用规则：
1. 徽标 = 浅底 + 深字 + 同色系描边 + 符号，**符号与颜色双编码**（色觉障碍可辨，见 §10）；徽标字号 11px/700、圆角 `xs`，禁止小于 11px。
2. 引用校验失败的段落自动降级为 `归纳`（对应 02 文档 §5.2），前端不渲染"事实"。
3. 徽标跟在段落末尾，不前置、不单独成行；讲解卡整卡若有任何生成段，卡片 chip 标注「由智能体生成」。
4. 证据缺口行：警示色文字 + ⚠，放出处清单末尾，是出处清单的一部分。
5. 符号 ●◐○ 是纯排印字符（非 emoji，各平台渲染一致），语义自解释：实心=有出处落点、半圆=综合而来、空心=开放生成。

### 2.4 场景语义色

| 场景 | 底/字 | 说明 |
|------|-------|------|
| 私人入口 | `#F1ECFA` / `#6B46C1` | 入口行内小标「私人入口」，仅自己可见的内容 |
| 入口模板 | `#EEF2FD` / `#3A5FCD` | 「入口模板」= 平台提供的可复制能力，归主色系 |

| 已停用/驳回 | `#FDECEA` / `#C0392B` | 工作台状态标签 |
| 分享提示条 | `#FDF6E3` / `#8F5E12`，边框 `#F3DDAD` | 「已自动移除 N 条私密内容」等 |

### 2.5 功能色

成功 = 事实绿 `#1F7A4D`（同源复用，不另设）；警示 = `#8F5E12`；危险 = `#C0392B`；信息 = 主色。危险按钮（工作台）为白底红字红描边，不做红底实心（降低误触权重）。

| 组合 | 比例 | 组合 | 比例 |

| sub `#6E675C` / 白 · / bg · / surface-2 | 5.59 · 5.05 · 4.96 | synth `#0E7490` / 白 · / soft · / surface-2 | 5.36 · 4.74 · 4.75 |

### 2.8 配比与禁忌

- 页面配比约：中性底/面 70%、文字 20%、品牌色 ≤8%、可信色+功能色 ≤2%（可信徽标小而准，出现在每一处可信内容上，但**不构成大面积色块**）。
- 禁忌：正文用品牌色；同屏超过 1 个实心主色大按钮；可信色做渐变；色值绕过 Token 硬编码。

## 3. 字体排印

**两层字族系统**（P6）：

- **显示层 · 宋体**（`--ke-font-display`，知识与品牌层专用：卡片标题、专题名、页面大标题、统计指标数）：
  `"Noto Serif SC", "Songti SC", "STSong", "Source Han Serif SC", "SimSun", serif`——系统栈优先、不加载外部字体（保首屏 ≤1.5s 指标）；分享页/小程序二期可引入子集化思源宋体 woff2 提升低端安卓渲染。
- **界面层 · 黑体**（`--ke-font`，正文/表单/工具界面）：
  `-apple-system, BlinkMacSystemFont, "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Microsoft YaHei", sans-serif`

规则：宋体只出现在「知识与品牌层」，工作台工具界面（表格/表单/按钮）一律黑体——字族切换即信息层级的切换。

### 3.1 探索端字阶（H5，基准 375px 逻辑宽度）

| 级 | 字号/行高/字重 | 用途 |
|----|---------------|------|
| 页标题 | 20 / 1.3 / 900 **宋体** | 首页「知识探索」 |
| 卡标题 | 20 / 1.4 / 900 **宋体** | 图文卡/讲解卡标题（知识对象名） |
| 小标题 | 15 / 1.4 / 700 黑体 | 区块标题、按钮文字 |
| 正文 | 14 / **1.8** / 400 | 卡片正文（长文阅读行高，两端对齐） |
| 通用 | 13.5 / 1.6 / 400 | 服务栏、入口名 |
| 次要 | 12 / 1.6 / 400 | 副标题、说明、表单标签 |
| 微字 | 11 / 1.5 / 400–700 | 徽标、角标、chip、底栏标签 |

### 3.2 工作台字阶（桌面，信息密度优先，全部黑体）

| 级 | 字号/行高/字重 | 用途 |
|----|---------------|------|
| 指标数 | 27 / 1.2 / 900 **宋体** · `font-variant-numeric: tabular-nums` | 统计卡数值（表格化数字防跳动；宋体大数字是品牌层在工具界的唯一露出） |
| 页/面板标题 | 15 / 1.4 / 700 | 顶栏、面板头 |
| 区块/字段标签 | 12 / 1.4 / 700 | 表单字段 |
| 基准 | 13 / 1.6 / 400 | 表格、表单、正文（Element Plus `--el-font-size-base:13px`） |
| 次要 | 12 / 1.6 / 400 | 面包屑、说明、KV 键 |
| 微字 | 11 / 1.5 / 600 | 状态标签 tag |

规则：信息性文字最小 11px 且须达对比度；正文禁斜体；看板/配额/统计数字用 `tabular-nums`；标题超长省略号（单行）不折行。

## 4. 布局与栅格

### 4.1 探索端（H5）

- 适配 360–430px 逻辑宽度，设计基准 375；单列布局。
- 页面左右边距 16；卡片间距 12；区块标题上距 16、下距 6。
- 卡片内边距 16（主卡 16–18）；卡片圆角 `l`(12)。
- 底部常驻区（服务栏/追问条/底导航）：高 ≈64 + `env(safe-area-inset-bottom)`；内容滚动区底部让出 96px 防遮挡。
- 顶栏（二级页）：返回按钮 + 面包屑 + 路径入口按钮，各 34×34（触区扩至 44，见 §10）。
- 分享页同此规范，但免登录路由独立 chunk（首屏 ≤50KB gz，02 文档 §8）。

### 4.2 工作台（Web）

- 侧栏固定 220（暗色）+ 顶栏 56 + 内容区 padding 24；内容区最大宽 1440 居中。
- 面板（表格容器）：圆角 `l`(12)、白底、1px line 描边；表头 `surface-2` 底、高 ≈40；单元格 padding 12×14；行 hover `--ke-surface-2`。
- 常用双栏 `1.1fr / 0.9fr`、统计三栏；栅格 12 列、gap 16，最小支持 1280 宽。
- 抽屉宽 460（>90vw 时取 90vw），右侧滑入。

### 4.3 断点（工作台）

| 断点 | 宽度 | 行为 |
|------|------|------|
| `lg` | ≥1280 | 标准三段布局 |
| `md` | 1024–1279 | 侧栏可折叠为 64 图标态 |
| `sm` | <1024 | 工作台不做响应式适配（桌面工具，P2 再议） |

## 5. 形状与层级

**圆角**（`--ke-radius-*`，印刷感：克制、偏小）：`xs 3`（徽标/角标/色块）· `s 5`（输入框、小件）· `m 8`（按钮/入口行/路径节点）· `l 12`（卡片/面板/强调面）· `full 999`（chip/进度条）。同屏圆角不超过 3 种档位；不做超大圆角（≥20px）与「果冻感」造型。

**描边与成型**：**卡片靠 1px 细线描边成型，不用静态阴影**（P6）；默认 1px `--ke-line`；输入框 1px `--ke-line-strong`，聚焦换主色 + 聚焦环；虚线仅用于「新增入口」按钮（1.5px dashed `rgba(58,95,205,.5)`）与分期灰态。

**阴影与层级**（阴影只给悬浮层）：

| Token | 值 | 用途 |
|-------|-----|------|
| `--ke-shadow-1` | `0 2px 8px rgba(38,34,29,.07)` | hover 提升、下拉浮层 |
| `--ke-shadow-2` | `0 8px 24px rgba(38,34,29,.12)` | 抽屉、下拉浮层 |
| `--ke-shadow-3` | `0 16px 48px rgba(38,34,29,.18)` | 模态弹层 |
| `--ke-focus` | `0 0 0 3px rgba(58,95,205,.25)` | 键盘焦点环（强制） |

z-index：sticky 顶栏 10 · 底部常驻栏 20 · 抽屉 50 · 模态 100 · Toast 200。透明遮罩 `--ke-mask` 用于抽屉/模态。

## 6. 图标与插图

1. **系统操作图标 = 自绘 SVG 线性图标集**（24 网格、stroke 1.7、圆端点、`currentColor`），统一放 `packages/shared/icons/`（sprite `<symbol>`），双端引用同一份。**禁止用 emoji 做控件/导航/服务图标**——emoji 渲染随平台漂移且观感廉价，是 v1.0 被评审否决的主因（§12 B-5）。最小集 18 枚：返回 / 右箭头 / 指南针(路径) / 搜索 / 分享 / 收藏 / 时钟 / 书(讲清楚) / 天平(比较) / 层叠(整理) / 加号 / 锁 / 对勾 / 警示 / 人物组 / 笔 / 山形 / 殿顶·器物·声波（三专题）。
2. **路径心智锚点**：路径入口统一用「指南针」SVG 图标（v1.0 的 🧭 emoji 例外随之废除）。
3. **徽标符号 ●◐○ 是可信语言的一部分**（§2.3），纯排印字符、各平台渲染一致，不得删除符号只留色块，也不得替换为 emoji。
4. **emoji 降级为内容插图占位**：仅允许出现在专题封面占位、卡片插图占位等「内容位」，且二期随统一插画风格替换；出现在控件上一律视为缺陷。
5. **印章元素**：方形「探」章仅用于品牌位（规范页 / 关于页 / 分享页页脚），不做交互元素、不进业务组件。

## 7. 组件规范

> 组件分三层：**共享语义组件**（放 `packages/shared`，双端复用，对应 02 文档 §8）、探索端组件（Vant 基座）、工作台组件（Element Plus 基座）。凡列出「状态」的组件，状态缺失视为实现 bug。

### 7.1 共享语义组件（双端复用，规范核心）

**ClaimBadge 可信徽标**
结构：`符号 + 文案`，浅底 + 深字 + 同色系描边，圆角 `xs`，字 11/700，padding 1–2×7。
状态：`fact` ● 事实 · `synth` ◐ 归纳 · `gen` ○ 生成。
规则：挂段落末尾；读屏朗读完整释义（§10）；工作台审核中心预览与分享页必须用同一组件——**可信标识在哪个端都长一样**。

**CitationTag 引用角标**
结构：上标 `[n]`，主色 11/700，`vertical-align: super`。
状态：默认可点 → 点击弹出/滚出处清单对应行并高亮；出处被剥离（校验降级）时角标不渲染。
规则：编号与卡片「来源依据/出处清单」一一对应；正文内不得出现裸链接替代角标。

**SourceList 出处清单**

## 9. 动效

| 场景 | 时长/缓动 | 效果 |
|------|----------|------|
| 按压反馈（探索端按钮/入口行） | 120ms | `scale(.97)` |
| 屏幕切换 | 150ms | 透明度渐变（不位移，避免方向歧义） |
| 展开/收起（入口折叠、下拉） | 250ms | 高度过渡 |
| 抽屉滑入、Toast 淡入 | 250ms | ease-out |
| Spinner | 1s linear | 旋转 |
| 骨架 shimmer | 1.4s ease-in-out | 无限循环 |

统一：`--ke-dur-fast:120ms / --ke-dur-base:150ms / --ke-dur-slow:250ms`；`--ke-ease: cubic-bezier(.25,.8,.35,1)`。**不做**入场级联、视差、弹跳；`prefers-reduced-motion: reduce` 时关闭位移动画仅保留透明度（§10）。

## 10. 无障碍

1. **对比度**：全部文字/底组合 ≥4.5:1（§2.7 实测表）；图表线条类 ≥3:1。
2. **触控目标**：可点元素 ≥44×44（视觉小于此值时用 padding 扩热区：chip、角标、路径点）。
3. **键盘**：所有交互可 Tab 到达；焦点环 `--ke-focus` 强制显示（`focus-visible`），不得 `outline:none` 裸奔；抽屉/弹层打开时焦点圈定（focus trap）。
4. **读屏**：ClaimBadge `aria-label` 模板——事实=「事实陈述，有出处」/归纳=「归纳推断，基于出处综合」/生成=「生成内容，仅供参考」；CitationTag `role="button" aria-label="查看出处 n"`；分期灰态加 `aria-disabled`。
5. **动效**：尊重系统减动效设置（§9）；spinner 之外无高频闪烁（防光敏）。
6. **双编码**：可信三档、场景标签色弱可用（符号/文字同现，§6.3）。

### B. v1.0 → v1.1（「纸墨编辑部」方向修订）

v1.0 评审结论：视觉呈现"像 AI 生成的模板"。逐条症状与修正（可信三色语义不变，仅呈现语言升级）：

| # | v1.0 | v1.1 | 原因 |
|---|------|------|------|
| B1 | 中性色为冷蓝灰（bg `#F4F6F9` 系） | 转暖为纸墨系（bg `#F7F3EB`、ink `#26221D` 等，§2.6） | 冷灰白卡 + 柔阴影是通用 SaaS 模板配方；暖纸 + 细线是印刷物语言，贴合文化知识产品 |
| B2 | 圆角 6/8/10/12/16 五档 | 收紧为 3/5/8/12 四档（`xl` 移除） | 大圆角堆砌是「果冻感」模板特征；印刷感需要更小的圆角 |
| B3 | 卡片静态阴影 `shadow-1` | 卡片靠 1px 细线描边成型，阴影只给悬浮层 | 去「悬浮卡片海」模板感；层级由细线与留白表达 |
| B4 | 品牌渐变 `--ke-primary-grad` | 移除 Token；品牌强调面 = 深靛实底 + 描边按钮 | 靛紫渐变横幅是 AI 生成页第一特征；图表渐变保留为组件内部样式 |
| B5 | emoji 作系统图标（💡⚖️🗂️🧭 等） | 自绘 SVG 线性图标集（24 网格 / stroke 1.7 / `currentColor`，§6），emoji 降级为内容插图占位 | emoji 渲染随平台漂移、观感廉价，是「AI 味」最大来源 |
| B6 | 可信符号 📎✦✧（📎 为 emoji 渲染） | 改纯排印字符 ●◐○，语义自解释（实心=落在出处 / 半圆=综合 / 空心=开放生成） | 排印字符跨平台一致；符号语义与可信档位形成叙事 |
| B7 | 全站黑体、无字体身份 | 两层字族：显示层宋体 900（知识与品牌层）× 界面层黑体（工具层），§3 | 字体是第一身份；宋体呼应书院/文化气质，且字族切换即信息层级 |
| B8 | 生成色文本 `#B45309` | 加深为 `#A85510` | 暖次级面 `#F5F1E8` 上 4.45:1 不达 AA → 全组合 ≥4.69:1 |
| B9 | 工作台侧栏冷蓝黑 `#1C2333` 系 | 暖墨 `#262119` 系（side-text `#B0A794` 6.70:1、side-text-2 `#989180` 5.10:1） | 与纸底同调；原 side-text-2 `#8E99AE` 在新底上仅 4.26:1 已随之修正 |
| B10 | 正文行高 1.75 | 1.8 | 纸底阅读行距微增，配合两端对齐的刊物排版 |
