# 04 主题与 UI 规范 · v2 知识图鉴

> 2026-10-02。用户确认「知识图鉴」方向，覆盖探索端 H5、创作工作台、双端登录和分享页。
> 正式实现：`frontend/packages/shared/src/tokens.css`、`styles/base.css`、`styles/theme-vant.css`、`styles/theme-element.css`。
> 离线规范：`prototype/styleguide.html`。双端交互原型仍用于演示流程；登录示例与组件状态见规范页。
> 本版替代 v1.1「纸墨编辑部」的色板、排版和组件外观；需求、接口、角色与业务状态保持原契约。

## 1. 设计原则

1. **专题是封面，知识是图版。** 书院建筑、食材与声波使用独立图形语言；首页以一大两小的专题封面构成入口。
2. **用排版建立层次。** 大宋体标题、图版编号、细线和留白承担组织；正文、问题入口与工具区的密度不同。
3. **好奇有路线。** 返回、路径与当前节点清晰可见；树形结构遵循真实父子关系，点击历史节点仍先确认接续。
4. **内容有来路。** 引用角标、出处清单、可信徽标、证据缺口与生成说明保留。图形仅为专题示意，不冒充实测建筑图。
5. **状态诚实。** 静态专题计数和推荐继续标注「示例 / 演示」；未上线能力按分期灰态；请求失败继续展示原因与重试入口。
6. **工具有密度。** 工作台是浅色编目桌面，优先展示标题、模板、状态、版本、更新时间和现有行操作。

## 3. 字体与排印

- 显示层：`--ke-font-display`，Noto Serif SC / Songti SC / Source Han Serif SC / SimSun。标题使用 400 字重，保留宋体笔画差异。
- 工具层：`--ke-font`，PingFang SC / Microsoft YaHei / Noto Sans SC。表单、表格、导航与按钮使用黑体。
- 索引层：`--ke-font-mono`，Bahnschrift / DIN Alternate / Consolas。用于图版编号、英文眉标与数字。
- 使用本地字体回落，核心页面不依赖远端字体加载。

| 场景 | 字号 / 行高 | 字重 |
|---|---|---|
| 首页导语 | 32–42px / 1.4 | 宋体 400 |
| 阅读标题 | 36px / 1.4 | 宋体 400 |
| 专题标题 | 24px，主专题 30px | 宋体 400 |
| 长文正文 | 15px / 2 | 黑体 400，左对齐 |
| 小节标题 | 17px / 1.5 | 黑体 600 |
| 工作台页标题 | 30px / 1.5 | 宋体 400 |
| 登录显示标题 | 桌面 36–58px，手机 30px / 1.45 | 宋体 400 |
| 登录表单标题 | 桌面 32px，手机 28px | 宋体 400 |
| 工具正文 | 12–14px / 1.6 | 黑体 400–700 |
| 索引 / 说明 | 10–11px | 清楚的辅助层，不承担主要操作 |

## 4. 布局

### 4.1 探索端

- H5 单列，验证 360–430px。桌面阅读区域最大 560px，居中，外侧为灰绿画布。
- 页面水平边距 24px，标题与区块有明确垂直间距；分享页仍使用自己的轻量样式。
- 顶栏 60px，普通返回与路径触区 44px；二级页内容顶部让出 80px 左右。
- 底部服务、追问、成果、分享和路径操作栏与正文等宽居中，保留 safe-area。
- 首页主导航：发现 / 我的路径 / 我的。匿名进入个性化页仍由既有路由守卫跳转登录。

### 4.2 工作台

- 浅色侧栏 214px，68px 顶栏，正文边距 36px；≤900px 收紧到 176px 侧栏和 24px 正文边距。
- ≤600px 菜单变为横向滚动，正文独立滚动；表格保留自身横向滚动以支持真实字段。
- 列表筛选用下划线表达当前状态，行边界用细线，主按钮维持单一松绿行动层。

### 4.3 登录扉页

- >760px：专题叙事与表单左右分栏，最大 1260px；品牌顶栏最大 1440px。
- ≤760px：产品介绍、专题索引和表单上下排列，隐藏大图版，优先保证输入区域宽度。
- 两端共用 `base.css` 布局，分别保留自己的登录脚本。探索端验证码 / 密码切换、60 秒重发倒计时与站内 redirect 均沿用既有契约；工作台仍用密码登录。
- 手机验证码有显式 label、数字输入与 `one-time-code` 自动填充；错误用 `role="alert"` 和危险色左线；提交期间按钮禁用。

## 5. 形状与动效

- 圆角：xs 2px / s 3px / m 4px / l 5px；999px 只用于点、圆形符号和既有小徽标。
- 常规封面与阅读区不用阴影；抽屉、弹层保留 shadow-1 / 2 / 3。
- 图版 hover 轻微上移 4px；焦点用可见描边。触摸端不依赖 hover 才能发现操作。
- 尊重 `prefers-reduced-motion`，取消非必要位移与长过渡，保留业务状态文字。

## 6. 图形与图标

- `ThemeArtwork.vue`：书院建筑、食材与声波，纯 SVG，无外部位图依赖；未知专题显示中性的资料图形。
- 专题图版使用 `aria-hidden`，功能标题由独立文本提供；在阅读页标注「专题示意图」。
- 真实配图仍优先展示，alt 使用内容配置并回落到卡片标题；不会被装饰图版替换。
- 23 个既有 `KeIcon` symbol id、语义和业务用途保留；规范页与交互原型复用同一套系统图标。

## 8. 状态与边界

- Loading / error / empty / disabled 状态沿用既有真实结果；不会用样例数据填补请求失败。
- 登录后才能保存路径、查看私有入口或执行受保护操作；权限仍由原守卫和后端执行。
- 内容状态继续区分草稿、待审核、已发布、停用；送审与停用流程不变。
- 实际生成结果仍呈现事实 / 归纳 / 生成、出处、过滤说明和警示。分享保持私密剥离与生成标识。
- 页面渲染不改变探索节点挂接、游标、配额、幂等提交或服务轮询。

## 9. 技术落地

- 保留 Vue3、Vant、Element Plus 和现有 pnpm workspace；不引入新的运行依赖。
- 通过共享变量传播双端视觉；组件特有布局写在对应 Vue 样式，避免用全局规则改变通用第三方弹层位置。
- 分享继续作为懒加载 chunk，保持原 ≤50KB gzip 的检查。

## 10. 可访问性与验证

- 中文标题、label、按钮文字承担主要信息；纯英文索引只做辅助。
- 键盘可见焦点、44px 主要触区、错误 `role="alert"`、输入自动填充和状态双编码。
- 移动页不得横向溢出；多层路径、长标题、窄屏表单与固定操作区要单独检查。
- 执行 `pnpm --dir frontend lint`、`typecheck`、`build`、`test`；并在浏览器检查真实页面和登录方式切换。

## 12. v1.1 → v2

- 靛蓝 / 暖纸切换为松绿 / 雾白，新增嫩黄行动与三专题封面色。
- 大圆角统一卡片切换为封面、细线内容行和连续阅读图版；显示字体由重字重切换为宋体 400。
- 图标专题格切换为专题图版；全宽 H5 在桌面改为最大 560px 阅读区。
- 深色侧栏切换为浅色编目桌面；登录由居中盒切换为有内容叙事的扉页。
- 既有需求、接口、鉴权、服务、可信表达和分享边界继续有效。
